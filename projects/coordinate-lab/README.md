## 已经确认的结论

### 1. 3857 换算是确定性的，四方结果完全一致

同一个点（广州 113.2644, 23.1291）在四个独立实现下的结果：

| 实现 | x_3857 | y_3857 | 来源 |
| --- | --- | --- | --- |
| PostGIS `ST_Transform` | 12608535.33 | 2647638.58 | 见 [week01.md 第四节](../../notes/week01.md) |
| 前端 JS / `ol/proj` | 12608535.33 | 2647638.58 | 同上 |
| Python `pyproj 3.8.0` | 12608535.33 | 2647638.58 | 本目录 `w1_proj.py` |
| QGIS 3.44.15 | 待实测 | 待实测 | 实验手册实验一 |

**结论**：坐标转换是**封闭公式**，不是迭代近似，所以任何标准实现都应给出相同结果。
以后遇到"图层对不上"，可以用这个点做**基准测试（benchmark）**来交叉验证，而不是靠猜。

> 差异排查提示：若某工具算出的值与此不同，先查三件事——CRS 轴序（lat/lon 是否反了）、
> 是否用了 `always_xy` 之类的参数、以及该工具是否用了非标准的椭球参数。

### 2. 4326 与 4490 的转换结果相同，但法律上必须用 4490

PROJ 转换下二者完全一致（椭球扁率倒数只差第 8 位小数）。
但**中国境内正式成果必须使用 CGCS2000（EPSG:4490）**——这是合规要求，不是精度问题。

### 3. Web 墨卡托在非赤道地区系统性放大：系数 = 1/cos(纬度)

| 纬度 | 理论放大系数 | 含义 |
| --- | --- | --- |
| 0° | 1.0000 | 赤道处准确 |
| 23.13°（广州） | 1.0874 | 距离统计偏大 8.7% |
| 45°（哈尔滨） | 1.4142 | 偏大 41% |
| 60.5° | 2.0308 | 偏大 103% |

**推论（W10 会用到的坑）**：在 3857 下做"500 米缓冲区""服务区覆盖"这类分析，
在广州会多算约 8.7%，在高纬地区会严重失真。
精确量算要用 4326 + 椭球，或换投影坐标系（如 CGCS2000 高斯克吕格）。

### 4. GCJ-02（高德/腾讯）偏移量实测

| 城市 | 偏移距离 | 方向 |
| --- | --- | --- |
| 北京天安门 | 724.3 m | 东 695 m / 北 204 m |
| 广州塔 | 676.0 m | 东 593 m / 南 324 m |
| 上海人民广场 | 563.4 m | 东 504 m / 南 253 m |
| 三亚 | 497.1 m | 东 456 m / 南 198 m |
| 乌鲁木齐 | 367.8 m | 东 317 m / 北 186 m |

**三条结论**：
1. 偏移量**随位置变化** → 不能用固定常量去减
2. 量级 **100~700 米** → 在 z=18 底图上肉眼明显
3. 偏移**非线性** → 必须用算法转换，不能线性平移

### 5. 球面 vs 椭球：差 2.66 km

北京–上海球面大圆 1068.51 km，PostGIS `geography`（WGS84 椭球）1065.85 km。
前端 `ol/sphere` 用球面模型，数据库 `geography` 用椭球模型 —— **量算结果会有系统性差异**。

### 6. WKT 首词快速判类型

- `GEOGCS` = 地理坐标系（单位**度**）
- `PROJCS` = 投影坐标系（单位**米**）

3857 正式名称是 **Pseudo-Mercator**（伪墨卡托），因为它把椭球**当正球体**处理
（`+a=6378137 +b=6378137`）。这正是它在高纬放大的根本原因。

## 复现方式

```bash
gis                    # 进仓库
conda activate webgis  # 激活 W1 环境
python projects/coordinate-lab/w1_proj.py          # 全部
python projects/coordinate-lab/w1_proj.py tile     # 只跑瓦片编号
python projects/coordinate-lab/w1_proj.py offset   # 只跑 GCJ-02 偏移
python projects/coordinate-lab/w1_proj.py project  # 只跑投影换算
```

Node.js 版：`node projects/coordinate-lab/coord.mjs`
